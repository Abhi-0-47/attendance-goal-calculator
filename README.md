📊 Attendance Predictive Calculator

A specialized diagnostic tool designed for academic compliance planning. This application moves beyond simple tracking by utilizing a Predictive Logic Engine to calculate exactly how many classes a student needs to attend—or can safely miss—to hit a specific percentage goal.
🚀 The "Predictive" Advantage

Most trackers only show you the past. This tool calculates the future:

    The Buffer Logic: If you are above 75%, it calculates exactly how many classes you can miss before falling below the threshold.

    The Recovery Logic: If you are below 75%, it calculates the exact "attendance streak" required to fix your percentage.
🛠️ Technical Implementation

    Backend: Python 3 & Flask Micro-framework.

    Algorithm: Iterative while-loop simulation to solve for target variables.

    Frontend: Responsive HTML5/CSS3 Dashboard.
  📦 How to Run Locally

    Clone the project: git clone https://github.com/Abhi-0-47/attendance-goal-calculator.git
    Install Flask: pip install flask
    Launch: python app.py
    View: Open http://127.0.0.1:5001 in your browser.
